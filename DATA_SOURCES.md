# Data Sources & Taxonomy Provenance

## Taxonomy Foundation
- **Base Taxonomy**: Inspired by ESCO (European Skills, Competencies, and Occupations) classification with custom Tamil Nadu and Indian industry mappings.
- **Skill Aliases**: 50+ alias mappings resolving variants (e.g. `ReactJS` / `React.js` -> `React`).

## Job Posting Provenance
- `REAL_API`: Sample jobs ingested via API endpoints.
- `OPEN_DATASET`: Cleaned job listings from open technology datasets.
- `MANUAL_IMPORT`: Admin imported job CSV/JSON structures.
- `SYNTHETIC`: Deterministic synthetic seed data clearly labeled as **Prototype Data**.
